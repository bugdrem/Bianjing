# 项目基础规范（Rules）

> 本规范适用于《汴京盛卷》（Bianjing）全部开发工作，作为每次调整的约束基线。源自 `.qoder/rules/Rules.md`，经整理完善。

## 1. 技术栈

- 引擎：Godot 4.x（Forward+ 渲染，.NET 8 / C# 12）
- 语言：**不使用 GDScript，全部逻辑用 C#**
- 第三方依赖：**不引入 NuGet 包**，除非与用户明确讨论后同意
- 目标平台：PC（Windows / Linux），暂不考虑移动端

## 2. 开发阶段与兼容性

- 当前为**开发版本**，**不考虑历史存档兼容性**（早期阶段，预计会大幅重构）
- 若新功能与现有代码结构不匹配：**不要打补丁，应寻找合适的方案重构**

## 3. 代码与注释

- 注释率不低于 30%（代码与业务逻辑注释）
- **全英文开发**：目录名、文件名、代码标识符一律英文
- 中文仅作为注释使用

## 4. 决策与提问

遇到以下任一情况**立即停止并提问，禁止猜测**：

- 需求模糊
- 遗留逻辑不确定
- 需新增依赖
- 跨模块影响不明
- 业务逻辑与代码冲突

## 5. 文档与配置

- 每次调整都在 `specs/` 目录更新对应日志
- 所有常量与公式统一存放于 `configs/` 目录（不在业务逻辑中硬编码字面量）
- 游戏背景优先参考中国古代**宋 / 唐**制度，其次为其他朝代
