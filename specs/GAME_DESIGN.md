# 汴京盛卷 — 玩法设计与第一阶段开发计划

> 由 `.qoder/specs/汴京城建游戏框架_task-392.md` 整理而来。本文为初始设计框架；其中「方块 / 胶囊占位」等早期美术描述已被实际的宋风建筑模型与骨骼村民取代（详见各子系统 spec）。

## 1. 游戏设计概要

**核心幻想**：玩家扮演获得封地的王爷，从一片荒地（河畔平原）起步，通过数十年游戏时间的建设与治理，最终呈现清明上河图般繁华的都城。

**核心循环**：

```
规划道路 / 划定坊区 → 建造官方建筑（宫殿 / 官府 / 军营 / 公共设施）
→ 吸引流民迁入 → AI 居民在住宅坊内自行建房、经商、开工坊
→ 收税获得钱粮 → 解锁更高级建筑与更大城区
→ 城市升级（村落 → 集镇 → 县城 → 州府 → 都城）
```

**两类建设主体**（与《天际线》的差异点）：

- **玩家直接建造**：宫殿、官府（衙门 / 税署 / 府库）、军营校场、公共设施（水井、寺庙、桥梁、城墙城门、瓦子 / 市楼）。
- **AI 居民自动建造**：玩家只划定「住宅坊」「市坊（商业）」「工坊（工业）」区域，居民根据宜居度 / 繁荣度自动在区域内临路地块建房、开店、设工坊，并随需求升级建筑等级（草屋 → 瓦房 → 楼阁）。

**关键数值系统**（第一阶段先做简版）：

- 资源：钱（税收）、粮（粮田 / 漕运）、人口、治安、宜居度。
- 时间：可暂停 / 1x / 2x / 3x，按「月」为最小结算单位；一旬 = 一游戏日，一月 = 三旬，季节影响画面与产出（后期）。
- 里坊制吸引力模型：坊内地块的吸引力 = 临路 + 靠近水井 / 市场 − 靠近工坊污染，决定居民建房位置与升级速度。

## 2. 技术架构（Godot 4.7 / C# / .NET 8）

**地图**：纯 C# 数据层网格（首版 128×128，格约 4m），每格记录地形 / 道路 / 建筑占用 / 坊区类型 / 吸引力缓存；**不使用 Godot 内置 GridMap 节点**，渲染层用 `MultiMeshInstance3D` 批量绘制方块占位，后期直接替换为国风模型而不动逻辑。

**寻路**：基于道路网格的 `AStarGrid2D`（Godot 内置），居民只沿道路移动；建筑必须临路才有效（与《天际线》一致的「连通性」检查）。

**模拟**：混合式——宏观统计模拟（人口 / 税收 / 需求按月结算，不逐人算账）+ 微观表现代理（少量可见小人沿路行走营造烟火气，Caesar / Banished 风格），避免全代理模拟的性能与复杂度。

**目录结构**：

```
res://
  scenes/Main.tscn            主场景（整合 node_3d.tscn）
  scripts/
    core/    GameClock.cs, GameState.cs, EventBus.cs
    map/     MapGrid.cs, Cell.cs, RoadNetwork.cs, GridRenderer.cs
    build/   BuildController.cs, BuildingDef.cs, PlacementValidator.cs
    zone/    ZoneController.cs, ZoneGrowthSystem.cs   (居民自动建房)
    sim/     PopulationSystem.cs, EconomySystem.cs, DesirabilitySystem.cs
    agents/  Walker.cs, WalkerSpawner.cs, CitizenAgent.cs (骨骼村民)
    camera/  RtsCameraRig.cs
    ui/      Hud.cs, BuildMenu.cs, TopBar.cs
  data/buildings.json          建筑/坊区定义（占地、造价、颜色、效果半径）
```

删除占位的 `NewScript.cs`。

## 3. 第一阶段实现范围（最小可玩闭环）

1. **相机**：RTS 风格——WASD / 边缘平移、滚轮缩放、中键旋转、Q/E 旋转，高度限制。
2. **地图与渲染**：128×128 平地网格 + 地面平面 + 网格线显示（建造模式下）；方块占位渲染器。
3. **建造系统**：底部建造菜单选择 → 鼠标网格预览（绿 / 红合法性提示）→ 左键放置、右键取消、拖动连续铺路 → 拆除工具。第一批可建：道路、宫殿(4×4)、衙门(2×2)、军营(3×3)、水井(1×1)、粮田(2×2)。
4. **坊区划定**：拖框划定住宅 / 市 / 工三类坊区（半透明色块覆盖显示）。
5. **居民自动生长**：每月结算——有住房需求且坊区内存在「临路 + 吸引力达标」空格时，自动生成民居方块；吸引力 = 临路 + 井 / 衙门覆盖 − 工坊邻近，简版即可。
6. **时间与经济**：顶栏显示 年 / 月、暂停与倍速；每月按人口收税、按建筑付维护费，钱不足停止生长。
7. **微观小人**：每栋民居按概率派出一个小人（已进阶为骨骼村民）沿道路随机走到市场 / 水井再返回，纯表现。
8. **HUD**：顶栏（钱 / 粮 / 人口 / 时间控制）+ 底部建造菜单 + 选中格信息面板（简版）。

## 4. 后续阶段（方向）

- **阶段 2**：城墙与城门、桥与河流、城外自由折线官道、建筑等级升级（草屋 → 瓦房 → 楼阁）。
- **阶段 3**：官吏任命系统、军队训练与治安 / 灾害事件、漕运贸易。
- **阶段 4**：替换国风美术资源、昼夜与季节、清明上河图式长卷截图模式。

## 5. 测试计划

- `dotnet build` 编译通过；Godot 编辑器运行 Main.tscn。
- 手动验收：铺一条路 → 划住宅坊 → 加速时间 → 观察民居自动出现、人口与税收增长、小人上路行走；拆路后该区域停止生长。

## 6. 假设

- 第一版全部用 BoxMesh / CapsuleMesh 占位，颜色区分类型，不引入任何美术资源（后续已进阶为宋风模型 + 骨骼村民）。
- 语言文本先直接写中文字符串，不做本地化框架。
- 存档系统留到阶段 2（先保证内存内闭环）。
