# 基础规则
- Godot 4.x(.NET 8 / C# 12)
- 不使用 GDScript,全部逻辑用 C#
- 不引入第三方 NuGet 包，除非明确讨论后同意
- 目标平台:PC(Windows/Linux),暂不考虑移动端
- 早期开发版本，不用考虑历史兼容性
- 不低于30%的代码或业务注释
- 全部使用英文开发,包括目录,中文仅作注释
- 遇到以下情况立即停止并提问，禁止猜测：需求模糊 | 遗留逻辑不确定 | 需新增依赖 | 跨模块影响不明 | 业务逻辑与代码冲突。
- 如果新功能和当前代码结构不匹配,不要打补丁,寻找合适的方案重构
- 每次调整都在specs更新日志
- 所有常量和公式都存放configs目录下
