# 古代封地经营游戏 - 经济系统需求文档

## 1. 货币体系

### 1.1 货币定义

| 货币 | 换算 | 用途 |
|:---|:---|:---|
| 铜钱（文） | 基础单位 | 所有日常交易、工资、物价 |
| 白银（两） | 1两 = 1000文 | 大额交易显示、俸禄、税收汇总 |
| 黄金（两） | 1两 = 10两白银 | 仅用于玩家资本展示，不流通 |

### 1.2 显示规则

- `< 1000文`：显示"XXX文"
- `>= 1000文`：显示"X两Y文"
- 国库总览：显示"金X两，银X两，钱X文"

## 2. 外部货币注入

### 2.1 王爷收入

| 来源 | 金额 | 频率 | 备注 |
|:---|:---|:---|:---|
| 开府安家银 | 100,000文 | 一次性 | 开局发放 |
| 月俸 | 8,000文 | 每月 | 前期核心现金流，中后期边缘化 |
| 朝廷赏赐 | 5,000-50,000文 | 任务触发 | 浮动金额，完成朝廷任务时获得 |

### 2.2 迁入者自带资金

| 类型 | 自带现金 | 技能 | 占比 |
|:---|:---|:---|:---|
| 归民 | 5-15文 | 无 | 高 |
| 寓商 | 2,000-5,000文 | 商业 | 低 |
| 散勇 | 100-300文 + 武器 | 战斗 | 低 |
| 客士 | 0-50文 + 书籍 | 文化 | 极低 |

**规则：**
- 金额在范围内随机生成
- 携带物品（武器、书籍）计入NPC资产，可变卖
- 占比决定各类型迁入者的出现权重

### 2.3 朝廷采购

- 机构：柴炭司（初期），后期可拓展织造局、军器局等
- **只从工坊批量收购，不从个体NPC收购**
- 采购有配额上限，价格固定
- 本质：用外部货币换取领地产品，是持续的货币注入

## 3. NPC就业系统

### 3.1 就业优先级

```
有技能 + 有岗位 → 直接入职
有技能 + 无岗位 → 临时采集，等待空缺
无技能         → 基础采集，积累经验等学徒岗
```

### 3.2 岗位匹配

- 建筑按等级自动生成岗位（见第8节）
- 岗位空缺时自动匹配：技能匹配 > 住所距离 > 等待时间
- 多人竞争时技能高者优先
- 入职后NPC获得月薪，月薪由建筑类型和等级决定

### 3.3 技能类型

| 技能 | 获取方式 | 适配岗位 |
|:---|:---|:---|
| 体力 | 默认拥有 | 樵夫、矿工、建筑工 |
| 手艺 | 工坊学徒积累 | 工匠、技工 |
| 商业 | 寓商自带/商铺积累 | 掌柜、账房 |
| 文化 | 客士自带/学堂学习 | 教师、医师 |

## 4. 土地与税收

### 4.1 土地规则

- **购地费**：NPC买地时一次性缴给玩家
- **土地税**：房屋建成后按月缴纳
- 购房 = 买地（钱归玩家）+ 建房（钱付给建筑工NPC）

| 地段 | 购地费 |
|:---|:---|
| 普通宅基地 | 10,000文 |
| 临街宅基地 | 15,000文 |
| 城中心地段 | 25,000文 |
| 资源点附近 | 8,000文 |

### 4.2 税种总览

| 税种 | 默认税率 | 可调范围 | 征收方式 |
|:---|:---|:---|:---|
| 土地税 | 3% | 1%-10% | 按月自动扣缴 |
| 商税 | 5% | 2%-15% | 交易发生时自动扣除 |
| 人口税 | 关闭 | 关闭/20% | 扣工资，降幸福，减人口流入 |

### 4.3 土地税明细

| 建筑 | 一级 | 二级 | 三级 |
|:---|:---|:---|:---|
| 民居 | 10文/月 | 25文/月 | 50文/月 |
| 宅邸 | 80文/月 | 150文/月 | 300文/月 |
| 工坊 | 40文/月 | 80文/月 | 150文/月 |
| 商铺 | 50文/月 | 100文/月 | 200文/月 |

### 4.4 人口税

- 默认关闭
- 开启后扣工资20%，幸福度持续下降
- 人口流入停滞，已定居者可能迁离
- 可随时关闭，关闭后缓慢恢复
- 定位：紧急筹款手段，非常规收入

## 5. 官营产业

### 5.1 定位

**只控制基础资源的上游开采，不加工，不零售。**

### 5.2 产业列表

| 官营产业 | 依赖资源点 | 产出 | 下游私营工坊 |
|:---|:---|:---|:---|
| 盐场 | 盐井/盐田 | 粗盐 | 精盐坊 |
| 冶铁所 | 铁矿 | 铁矿石 | 冶炼坊 |
| 林场 | 森林 | 原木 | 木材坊 |
| 采石场 | 石山 | 石料 | 石匠坊 |
| 酒曲司 | 粮食 | 酒曲 | 酿酒坊 |

### 5.3 运作规则

1. 玩家在资源点建造官营产业
2. 自动生产基础原料
3. NPC私营工坊自动进货，按固定价结算
4. 货款直接入国库
5. 私营工坊加工后卖给商铺，商铺再零售

### 5.4 产业链示例

> 官营盐场(粗盐) → 私营精盐坊(精盐) → 粮铺 → NPC消费者

玩家获利点：官营利润 + 后续交易的商税

## 6. 民营交易链

### 6.1 核心规则

**单向不可跨级：**

> 采集者 → 初级工坊 → 高级工坊 → 商铺 → NPC消费者

### 6.2 各级定义

| 环节 | 角色 | 产出 | 下游 |
|:---|:---|:---|:---|
| 采集 | 无业NPC | 原木、兽皮、草药 | 初级工坊 |
| 初级工坊 | 木材坊、皮革坊 | 木板、皮革 | 高级工坊 |
| 高级工坊 | 家具坊、成衣坊 | 家具、衣服 | 商铺 |
| 商铺 | 家具铺、布庄 | 成品零售 | NPC消费者 |

### 6.3 库存与价格

- 各工坊和商铺有库存上限
- `库存 ≥ 80%`：降价10%
- `库存 ≥ 95%`：降价30%
- `库存 ≤ 20%`：涨价10%
- 价格浮动自动处理，保证链条不断

## 7. 建筑生长系统

### 7.1 民居三级

| 等级 | 名称 | 住人数 | 升级条件 |
|:---|:---|:---|:---|
| 一级 | 茅草屋 | 1-2人 | - |
| 二级 | 木瓦房 | 3-4人 | 家庭资产达标 |
| 三级 | 砖木院落 | 5-6人 | 家庭资产达标 |

### 7.2 三级后转化

达到三级的民居，家庭资产达标时触发转化：

| 转化为 | 条件 |
|:---|:---|
| 宅邸 | 资产很高，周边无资源点，无临街需求缺口 |
| 工坊 | 周边有资源点 + 该资源有稳定需求 |
| 商铺 | 临街 + 周边居民消费需求未被满足 |

转化后从一级开始，可继续升级。

### 7.3 工坊

| 等级 | 岗位数 | 效率 | 技能要求 |
|:---|:---|:---|:---|
| 一级 | 2 | 100% | 无 |
| 二级 | 4 | 150% | 2名熟练工匠 |
| 三级 | 6 | 200% | 1名高级技工 + 2名熟练工匠 |

### 7.4 商铺

| 等级 | 岗位数 | 服务范围 | 技能要求 |
|:---|:---|:---|:---|
| 一级 | 1 | 周边50格 | 无 |
| 二级 | 2 | 周边100格 | 1名熟练掌柜 |
| 三级 | 3 | 全城 | 1名大掌柜 |

## 8. 经济循环总览

### 8.1 启动

```
玩家获封 → 安家银到账 → 建官署、流民营、基础设施 → 迁入者抵达
```

### 8.2 运转

```
迁入者带现金 → 购地建房 → 入职或采集 → 
采集物资→工坊→高级工坊→商铺→NPC消费 → 
NPC领薪再消费 → 税收归玩家
```

### 8.3 增长飞轮

```
更多迁入者 → 更多劳动力 → 更多产业 → 更多税收 → 
更好设施 → 吸引更多迁入者
```

### 8.4 外部活水

```
月俸 + 赏赐 + 朝廷采购 → 持续注入新货币 → 
抵消税收回收 → 货币总量增长
```
