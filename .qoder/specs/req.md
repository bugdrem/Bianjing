# 古代封地经营游戏 - 经济系统需求文档

## 1. 货币系统

### 1.1 货币单位
- 基础货币：铜钱（文），所有交易的最小单位
- 进阶货币：白银（两），1两 = 1000文
- 储备货币：黄金（两），1两 = 10两白银 = 10000文

### 1.2 显示规则
- 金额 < 1000文：显示为"XXX文"
- 金额 >= 1000文：显示为"X两Y文"
- 国库总览：显示黄金/白银/铜钱三项

## 2. 外部货币注入

### 2.1 王爷收入
- 开府安家银：100,000文，开局一次性
- 月俸：8,000文，每月自动到账
- 朝廷赏赐：5,000-50,000文，完成朝廷任务时触发

### 2.2 迁入者自带资金
- 定义迁入者类型枚举：归民、寓商、散勇、客士
- 每种类型有固定的自带资金范围（见附表）
- 资金在NPC生成时随机确定，直接注入NPC资产
- 迁入者携带的特殊物品（武器、书籍等）计入其资产

### 2.3 朝廷采购
- 柴炭司等机构定期发布采购订单
- 订单有配额上限
- 采购价格固定
- 只从工坊/商铺收购，不从个体NPC收购

## 3. 税收系统

### 3.1 土地税
- 对所有非公共建筑按月征收
- 税额 = 建筑基础税率 × 等级系数
- 默认税率3%，可调范围1%-10%
- 建筑所有者自动缴纳

### 3.2 商税
- 对工坊→商铺、商铺→NPC的每笔交易自动扣税
- 默认税率5%，可调范围2%-15%
- 交易发生时自动扣除，无需玩家操作

### 3.3 官营利润
- 玩家建造的官营产业（盐、铁、特殊木材、酒曲）
- NPC商铺自动前来进货，按固定价格结算
- 货款直接计入国库

### 3.4 人口税（丁税）
- 默认关闭
- 开启后对所有工作NPC工资扣税，默认20%
- 开启后人口流入减少，幸福度持续下降
- 可随时关闭

## 4. NPC资产与就业

### 4.1 资产系统
- 每个NPC有资产属性（铜钱数量）
- 资产来源：自带资金、工资收入、经营收入
- 资产消耗：日常消费（食物、燃料）、购地、建房、升级建筑

### 4.2 就业系统
- 建筑根据类型和等级自动生成岗位
- 岗位属性：所需技能等级、月薪
- 无业NPC自动匹配周边空缺岗位
- 技能匹配度影响产出效率

### 4.3 阶层流动
- NPC资产超过阈值时触发阶层升级
- 阶层影响消费行为和居住需求

## 5. 建筑与交易链

### 5.1 交易链条
- 个体采集 → 初级工坊 → 高级工坊 → 商铺 → 消费者
- 链上每个节点只与上下游相邻节点交易
- 不允许跨级交易（个体不能直接卖给商铺）

### 5.2 工坊系统
- 分三级，每级岗位数递增（2/4/6）
- 二级以上需要熟练工人
- 三级需要高级技工
- 库存超过80%自动降价，低于20%自动涨价

### 5.3 商铺系统
- 分三级，每级岗位数递增（1/2/3）
- 服务范围随等级扩大
- 自动从上游工坊进货，自动向NPC销售
- 销售价格受库存影响浮动

### 5.4 民居生长
- 分三级，升级条件：家庭资产达标
- 三级后根据环境条件转化：
  - 周边有资源点+需求 → 工坊
  - 临街+消费需求未满足 → 商铺
  - 资产很高但无商业条件 → 宅邸
- 转化后的建筑从一级开始，可继续升级

### 5.5 官营产业
- 玩家建造，类型：制盐、冶铁等基础资源
- 自动生产，NPC商铺自动进货
- 进货价格固定
- 利润直接入国库

## 6. 物价参考基准

### 6.1 基础物价
- 1文 = 一个烧饼
- 3文 = 一捆柴
- 10文 = 一斤猪肉
- 100文 = 一把锄头
- 1000文 = 工匠月薪
- 10000文 = 一块宅基地

### 6.2 工资基准
- 学徒/杂工：300-500文/月
- 熟练工匠：800-1200文/月
- 掌柜/账房：1500-2500文/月
- 教师/医师：2000-3000文/月
- 樵夫/猎人：300-600文/月（不稳定）
