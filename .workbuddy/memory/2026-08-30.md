## 动物"没色彩 + 不会动"排查与修复

  不再依赖手算复合链，自然兼容 inst 自身带缩放/平移的情况。

## 湖面规则网格异常（已修）
- 现象：去雾后暴露——大面积湖面浮现 1m 周期的规则网格，窄河道看不出来。
- 根因：`WaterConfig.WaterEdgeOverlap = 0.7f` 让每个水面四边形**四向都外扩 0.7m**，
  1m 格子被扩成 2.4m，相邻水面互相重叠约 1.4m。半透明(alpha 0.85)逐层叠加 →
  每像素被 2~3 个水面覆盖，覆盖率按 1m 周期在 2/3 间规律变化 → 视觉上即规则网格；
  且叠加后实际不透明度 ≈99%，"透见河床"的设计效果其实早已失效。
- 修复：`AddWaterQuad` 改为**只在邻格非水（陆地/越界）的方向外扩**（保留"水平面钻到岸下、
  消除水陆交界锯齿"的原意图），水-水相邻方向共享边不重叠。新增 `IsWaterCell` 辅助
  （桥格含桥下水面，一并视为水面以保证连续）。
- 编译 0 警告 0 错误。待实跑：湖面网格应消失，且能隐约透见河床。
