## 修复：地图上的太阳显示为黑色
- 现象：上一轮为让太阳豁免地平雾，将其材质改为自定义 `ShaderMaterial`（`MakeSunMaterial`），结果太阳变黑盘。
- 根因：`uniform vec4 tint` + 每帧 `SetShaderParameter("tint", Color)`——Godot 4 的 vec4 着色器参数**不接受 `Color`**（只认 `Vector4`），写入被静默丢弃，tint 停在默认 (0,0,0,0)；而核心着色器是 `unshaded`（默认不透明），不透明混合下 ALBEDO=黑 → 黑圆盘。月亮用 `vec3 tint`+`float alpha`（与 Color/float 匹配）故正常。
- 修复：太阳改回与月亮一致的双 uniform——`uniform vec3 tint` + `uniform float alpha`，分别传 `Color` / `float`；核心混合由“不透明”改为 `blend_mix`（透明），即便参数异常也不会再出现不透明黑盘。雾豁免仍保留（自定义着色器不含雾）。
- 验证：`dotnet build -p:UseSharedCompilation=false` 0错0警告。
- 已把该 Godot 4.7 着色器坑写入 MEMORY.md（vec4/Color 静默丢弃 → 黑盘），供后续自定义着色器复用。

## 修复：人物面板（InspectPanel）白字 + 背景近白
- 现象：点选村民/居民后，详情面板正文白字、背景板也偏白，几乎不可读。
- 根因：① 正文 `_body` 是 `RichTextLabel`，其正文基色走主题 `font_color`；仅设节点级 `AddThemeColorOverride("font_color", Ink)` 才确保墨字（对比 `NewsPanel` 用普通 `Label` 直接吃主题 font_color，故正常）。② 毛玻璃面板在明亮天空后，模糊色偏白、仅混入 34% 宣纸色 → 整体近白，叠白字更看不清。
- 修复：
  - `scripts/ui/InspectPanel.cs`：`_body` 加 `AddThemeColorOverride("font_color", UiTheme.Ink)`；`_title` 同加墨字覆盖；`_bioBody` 改用 `UiTheme.Muted` 弱文色（明确非白）。（注：Godot 4 `RichTextLabel` 无 `DefaultColor` 属性，编译已验证。）
  - `scripts/ui/FrostedPanel.cs`：宣纸混入 `tint_strength` 0.34→0.5、不透明度 `alpha` 0.9→0.95，面板在亮天空后也明确呈宣纸色而非近白（全局所有毛玻璃面板同步受益）。
- 验证：`dotnet build -p:UseSharedCompilation=false` 0错0警告。

## 修复：人物/建筑面板除名字外仍白字 + 远景俯瞰有烟雾
- 现象（基于截图）：① 点选村民/居民后，「冯寅」（BBCode 蓝色人名）可见，其余正文（履历/需求）整片白——上轮修后仍白。② 远距俯瞰城池时城内朦胧、有烟雾感（俯瞰满雾）。
- 根因：① Godot 4 的 `RichTextLabel` 默认正文字色主题键是 **`default_color`，不是 `font_color`**；上轮 `AddThemeColorOverride("font_color", Ink)` 覆盖错了键名，对 `RichTextLabel` 等于无效——BBCode 显式 `[color=…]` 的文本（蓝/红）正常渲染，纯文本部分仍是 Godot 默认白字。`NewsPanel` 用普通 `Label` 故正常（`Label` 走 `font_color`）。② 上轮雾策略"按拉距从 0 升到 `HorizonFogDensity=0.0012`"——俯瞰（拉距远）即满雾，城市 200m 也约 21% 雾，导致俯瞰烟雾感。
- 修复：
  - `scripts/ui/UiTheme.cs`：增加 `t.SetColor("default_color", "RichTextLabel", Ink)`（真正的 RichTextLabel 默认正文字色）。
  - `scripts/ui/InspectPanel.cs`：`_body` 覆盖改为 `AddThemeColorOverride("default_color", UiTheme.Ink)`（替代上轮无效的 `font_color`）。BBCode 显式 `[color=…]` 不受影响（人名蓝/红）。
  - `scripts/configs/WorldConfig.cs`：`HorizonFogDensity` 0.0012→0.00025，凭指数衰减只让极远缘软化；200m 处≈5% 雾（肉眼无感）、1500m 处≈31% 雾（柔化地平硬边）。
  - `scripts/Main.cs`：`UpdateFog` 改为恒定低密度、不再按拉距升满，俯瞰也保持城市接近无雾。
- 验证：`dotnet build -p:UseSharedCompilation=false` 0错0警告。已把 `RichTextLabel` 默认色走 `default_color` 而非 `font_color` 这一 Godot 4 坑写入 MEMORY.md。

## 修复：读档列表（ItemList）鼠标悬浮时文字发白
- 现象：进入「读取存档」页，鼠标悬浮在存档行上时文字发白、和列表底色几乎重叠看不清。
- 根因：`UiTheme` 给 `ItemList` 只设了 `font_color=Ink`、`selected` 样式盒（浅青底），但**没设 `font_hover_color`** 与 `hovered` 样式盒——Godot 4 ItemList 默认给 hover 文字色偏白、悬浮底色也不可控，叠在浅米色毛玻璃面板上几乎不可读。`font_selected_color` 也未显式（主题级 Ink 不会被 ItemList 选中态继承）。
- 修复（`scripts/ui/UiTheme.cs`）：
  - 新增 `t.SetColor("font_hover_color", "ItemList", Ink)`、`t.SetColor("font_selected_color", "ItemList", Ink)`——所有行态文字一律墨字。
  - 新增 `t.SetStylebox("hovered", …)`、`hovered_selected`/`hovered_selected_focus` 三套样式盒（浅青 `CeladonL` 底）——悬浮/选中皆「浅青底墨字」高对比，风格与 `PopupMenu` 一致。
- 验证：`dotnet build -p:UseSharedCompilation=false` 0错0警告。

## 修复：顶/底栏依旧不是毛玻璃 + 上下贴边
- 现象（基于截图）：游戏主视图里顶栏（资源/时间/按钮）与底栏（建造菜单）仍呈"实色条带"——明显不是毛玻璃（毛玻璃应该透出背后城市的模糊色）；且两栏紧贴屏幕上下边缘，无呼吸感。
- 根因：`Hud.cs`（CanvasLayer）第一个子节点 `BackBufferCopy` 创建后**没显式设 `Rect` 覆盖整屏**，默认 256×256——`SCREEN_UV` 大部分位置对应不到 backbuffer 数据，shader 采样返回无效/默认色，毛玻璃退化为局部色块（叠加宣纸混入后看着像单色带）。`GameMenu` / `LoadingScreen` 同问题。
- 修复（5 个文件）：
  - `scripts/ui/Hud.cs`、`scripts/ui/GameMenu.cs`、`scripts/ui/LoadingScreen.cs`：创建 `BackBufferCopy` 后立即 `bbc.Rect = new Rect2(Vector2.Zero, win.Size)`，并订阅 `win.SizeChanged` 跟踪窗口尺寸变化（F11 全屏 / 分辨率切换跟新）。`Hud` 是用户报修的根因面板。
  - `scripts/ui/TopBar.cs`：`SetAnchorsAndOffsetsPreset(TopWide)` 后覆盖 `OffsetLeft=24 / OffsetRight=-24 / OffsetTop=16`——与屏幕边缘各留 16/24 边距，仍占满水平宽度与底栏对齐。
  - `scripts/ui/BuildMenu.cs`：同样改 `OffsetLeft=24 / OffsetRight=-24 / OffsetBottom=-16`，与屏幕下沿保留 16px 间距。
- 验证：`dotnet build -p:UseSharedCompilation=false` 0错0警告；`BackBufferCopy.Rect 全屏` 这条 Godot 4.7 坑已写入 MEMORY.md。
