# 2026-08-26 工作记录

## 天空天体系统（太阳/月亮）
- 新增 `scripts/sky/SkyBodies.cs`：`Node3D`，持有太阳核心+光晕（`Sprite3D`+程序化径向渐变纹理）、月亮（`Sprite3D`+相位 `ShaderMaterial`）、月光 `DirectionalLight3D`。
- 太阳方向由 `Main.UpdateDayNight` 每帧传入（已随一日六时平滑转动）；月亮方向 = -太阳方向，天然“太阳出→月落、太阳落→月升”，亮度反相。
- 月相 `phase` 由时钟连续计算：`(AbsoluteDay + Hour/24) / MoonCycleDays`，`MoonCycleDays = TimeConfig.DaysPerMonth`（一个月一次朔望，与月份挂扣）。
- 太阳颜色：地平红黄 `SunWarmColor` → 正午白 `SunNoonColor`，同步作用于精灵与平行光（`_sun.LightColor`）。
- 夜晚阴影改由月光投射：`_moonLight` 能量 = `MoonBaseEnergy × 月可见度 × 相位受光比例`，故满月阴影硬、弦月软（含此前“夜晚关太阳阴影”的逻辑改为月光照）。
- `WorldConfig` 新增 `SunWarmColor/SunNoonColor/MoonTintColor/MoonLightColor/MoonBaseEnergy/MoonCycleDays`；`NightSunEnergy` 0.4→0.15（夜间主体交月亮）。

## Godot 4.7 API 坑（本次实测）
- `ShaderMaterial` 无 `Transparency` 属性；透明度用着色器 `render_mode unshaded, blend_mix;`（配合 `ALPHA` 输出）。
- `DirectionalLight3D` 无 `ShadowColor` 属性（4.7 已移除/改名），直接删去即可。
- `Image.Create` 已过时 → 用 `Image.CreateEmpty(w,h,mipmaps,format)`。
- `Sprite3D` 用 `PixelSize=1` + `Scale` 控制世界尺寸；透明用 `MaterialOverride=StandardMaterial3D(Unshaded,Transparency=Alpha)`，叠加光晕用 `BlendMode=Add`；可见度淡入用 `Modulate`(a)。
- 编译 `dotnet build -p:UseSharedCompilation=false` 0错0警告。
