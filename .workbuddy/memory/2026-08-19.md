## 全量代码审查 + 修复（已确认真 bug 5 处，均已修复并通过 dotnet build）

**修复的真 bug：**
1. **WorldGenerator.cs** `GenerateAsync` 吞异常仍置 `Done=true` → 半成品地图直接进游戏。新增 `Failed/Error` 静态标志；LoadingScreen 增加 `OnError` 回调（默认源失败时走错误路径）；Main.NewGame 挂 OnError：GameState.I=null、恢复暂停、NotifyLoadFailed 提示。异常不再被当成成功。
2. **LifecycleSystem.cs** `MarryIntoNewHome`/`LeaveForNewHome` 扣房款后未调 `LandSaleToPlayer` → 婚房/分家建房的地价凭空蒸发（与 MoveFamilyToNewHouse 口径不一致）。已补 `LandSaleToPlayer(gs, cost);`。
3. **MapGrid.cs** 构造函数只初始化 `BuildingId=-1`，漏了 `LaneOwnerId`（struct 数组零初始化，字段初值不生效）→ 无主小路默认 0 被误判归属 building 0。已补 `_cells[i].LaneOwnerId = -1;`。
4. **BuildController.cs** `FillZone`（油漆桶）BFS 边扩散边 `ApplyZoneStamp`，扩散出图判未封闭后已改部分未回滚 → 玩家看到"未生效"却有部分分区被静默写入。改为先收集 visited、确认封闭后再统一落区。
5. **TechPanel.cs:118** 立项按钮直接拼"文"未走 `CurrencyHelper.FormatWen` → 与全 UI 货币单位不一致。已改用 `(long)def.CostMoney` 格式化。
