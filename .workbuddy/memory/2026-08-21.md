## 建筑/人物模型重构（参考宋风图）：骨骼村民 + glb 资源管线 + 预览同步

### Phase B — NPC 骨骼 + 4 套代码驱动动画（已完成）
- **关键发现：Godot 4.7.1 不存在 `Bone3D` C# 类型**（grep GodotSharp.dll + 临时反射工程确认）。骨骼只能用 `Skeleton3D` 的索引 API 操作：`AddBone(name)`、`SetBoneParent(child,parent)`、`SetBoneRest/Pose(idx,T)`、`FindBone(name)`；网格部件经 `BoneAttachment3D`（属性 `BoneName`）挂到骨头，其 Transform 跟随骨头（含 pose）。
- 骨骼层级 root→spine→{head, armL, armR}。骨头 rest 为纯平移（root@0, spine@腰高, head@颈-腰, armL/R@±armX,armY-腰），pose 为纯旋转 → 绕骨头 rest 原点旋转即理想关节枢轴。
- 重写 `scripts/agents/CitizenAnim.cs`：`ApplyPose(state, phase, skel, 5 个骨头索引)` 纯函数姿态库，直接 `skel.SetBonePose(idx,T)`（不再依赖 Bone3D）。4 态：Idle/Walk/Carry/Working。
- 改 `scripts/agents/CitizenAgent.cs`：`_Ready` 建 5 骨头 + 5 个 `BoneAttachment3D`，部件按骨挂载（下身→root、上身/腰带/背负→spine、头/发/帽→head、左/右袖→armL/armR）；`_Process` 每帧 `UpdateAnimState()` + 累加 `_animPhase` + `CitizenAnim.ApplyPose(...)`。动画走代码逐帧 pose（非 AnimationPlayer），便于 300 个 agent 的性能。

### Phase C — 建筑 glb 资源管线（已完成）
- 新增 `scripts/build/BuildingAssetLoader.cs`：静态缓存 `Dictionary<string,PackedScene>`；`LoadScene(path)` 失败/空路径返回 null；`FitAndPlace(instance,w,d,height,baseY,posX,posZ)` 递归遍历 `VisualInstance3D` 子节点用 `GetAabb()`（Node3D 无 GetAabb）+ 父链 `RelativeTo` 合成局部 AABB，按 `Mathf.Min(sx,Min(sy,sz))` 均匀缩放、底座落到 baseY。
