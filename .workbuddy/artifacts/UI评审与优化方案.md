# 汴京盛卷 · UI 评审与「新中式」优化方案

> 游戏背景：宋朝架空世界；UI 目标气质——**新中式·流行扁平版（国潮极简）**：宣纸白毛玻璃面板打底，黑色书法字为主，青色为辅，红色印章作点睛。整体走"当前流行的扁平简约"，轻、亮、留白多。
> 本文基于代码实测给出诊断、设计令牌、组件规范与 Godot 落地路线。
> **2026-08-24 修订轨迹**：① 首版"宣纸文书卡+朱砂印章+描金"被评年代感重 → ② 改"天青瓷+冷蓝墨+极简黑体"仍偏沉 → ③ 定稿为「宣纸白毛玻璃 + 无边框圆角按钮 + 黑色书法字 + 青为辅 + 红色印章点睛」的扁平国潮方向。

---

## 一、现状诊断（代码实测）

| 维度 | 现状 | 问题 |
|---|---|---|
| 设计系统 | 全项目 0 个 `.tres` 主题、0 个 `ttf/otf` 字体、0 处统一配色令牌 | 没有"系统"，完全无设计基线 |
| 控件外观 | 全部继承 Godot 4 默认扁平主题（中性冷灰、方角、无衬线） | 现代瑞士风，与宋韵冲突 |
| 配色 | 散落 `AddThemeColorOverride`：顶栏金 `#FFE680`/负红 `#FF4D4D`、加载屏暖米 `#E0D1AE`、菜单纯黑遮罩、灰提示 | 各说各话，无语义体系 |
| 面板 | `PanelContainer` 默认半透灰，无边框/底纹/留白框 | 像"工具"不像"游戏界面" |
| 字体 | 系统默认无衬线，标题无宋体/楷体 | 缺书法感与层级 |
| 按钮 | 默认方块扁平，`Flat` 与否混用，无悬停/激活美术，纯文字无图标 | 信息密度低、无辨识度 |
| 微交互 | 即显即隐，无缓动 | 生硬 |
| 信息架构 | 顶栏 / 底部建造菜单 / 左侧详情 / 侧面板（政策·财政·研习） | **结构合理，不必推翻** |

**结论**：架构可用，**最大缺口是没有统一视觉语言**。最佳收益点是"建一套中央主题 + 令牌"，而非逐文件改样式。

## 二、设计令牌系统（新中式·宋韵）

### 色板（语义化，供 `Theme` 与 `UiStyle` 统一引用）
> 基调是**浅**：宣纸白毛玻璃为面；**黑**书法字为主；**青**作辅色（选中/下划线/图标）；**红**仅作印章式点睛（极少量）。无金、无深蓝墨底、无描边按钮。

| 令牌 | Hex | 用途 |
|---|---|---|
| 宣纸白 paper-glass | `#FBF8F2` + `blur` | **面板主底**：宣纸白毛玻璃（暖白半透 + 1px 极淡边 `#E7DFCF`） |
| 墨字 ink | `#1F1B16` | 标题/正文（略带书法的黑色字体） |
| 弱文 muted | `#8A8276` | 次要/提示信息 |
| 青 celadon | `#2C8C82`（深 `#1F6B63`） | **辅色**：选中态 / 下划线 / 图标 / 高亮 |
| 黛 divider | `#E2D9C8` | 浅色面板上的分隔线 |
| 朱 seal | `#C0392B` | **点睛**：印章、关键强调（极少量，形如印章） |
| 负态 warn | `#C0392B` | 欠债/告警（同朱） |

**取消**：冷蓝墨深底、暖金、描金描边、深色实心卡——保持"浅、亮、扁平"。

### 字体
- **正文 / 标题**：**略带书法的黑色字体**——楷体（`KaiTi`/`华文楷体`，笔意更足）或宋体（思源宋体 `Noto Serif SC`，更端庄）；统一选用一种，黑字（`#1F1B16`）。这是"国潮"的关键识别度来源。
- 关键数字可加粗；层级靠字号与弱文灰区分，而非换字体。
- 落地：字体文件置于 `assets/fonts/`，`FontFile` 加载，注入 `Theme.DefaultFont` 与 `Theme` 的 `Font` 覆盖。

### 间距 / 圆角 / 边框 / 动效
- 间距：8pt 栅格（4/8/12/16/24），面板内边距 16，留白多。
- 圆角：按钮/卡片 10–12、大容器 14；**按钮统一圆角矩形、无边框**。
- 边框：面板仅 1px 极淡边 `#E7DFCF`；**不用描边按钮、不用粗块分隔**，分隔用黛色细线或留白。
- 阴影：极轻或不加（扁平风）；可用极淡投影做悬浮层区分，但克制。
- 动效：150–300ms `ease`，入场轻微上移淡入、按钮悬停微抬升。

## 三、组件规范（要点）

- **面板（宣纸白毛玻璃）**：`paper-glass` 暖白半透 + `blur` + 1px 极淡边，内边距 16；浅、轻、留白多，不压花纹。
- **按钮（无边框圆角矩形）**：纯填充圆角矩形、**无描边**；主操作=墨黑填充白字（或青填充白字）；常规=浅灰 `#EDE7DA` 填充墨字；选中态=青填充白字；悬停微抬升。
- **顶栏（宣纸白条）**：资源用黑书法字，财富可加粗；速率用无边框圆角按钮分段（当前档=青填充）；关键里程碑以一方小红印点缀（点睛，非常态）。
- **建造菜单（底部宣纸白 dock）**：分类为无边框圆角按钮（选中=青填充白字 + 细下划线）；建造项为无边框圆角小卡，配线性青图标（钱袋·粮·人·政·书·拆）。
- **详情面板（左侧宣纸白卡）**：标题用黑色书法字；**右上角一方朱红印章作身份/重点点睛**（形如印章、白字篆意，极少量）；逐行黑字，状态用青色。
- **进度条 / 勾选**：青填充、青勾选。
- **图标**：线性青小图标，克制不描金。

## 四、Godot 落地路线（零侵入优先）

1. **P0 字体资产**：`assets/fonts/` 放楷体/宋体（黑色书法字，如 `Noto Serif SC`/`KaiTi`）+ 备一份无衬线兜底；`UiFont` 加载并缓存。
2. **P1 中央主题 `UiTheme.cs`**：代码构建 `Godot.Theme`——`DefaultFont` + 全套 `StyleBoxFlat`（`PanelContainer`/`Button`/`Label`/`LineEdit`/`ProgressBar`/`CheckButton`/`OptionButton`/`ItemList`…），在 HUD 根节点（或 `GetTree().Root.Theme`）挂载 → **所有子节点自动继承**，无需改 12 个 UI 文件。
3. **P2 语义令牌 + `UiStyle` 助手**：`MakeButton(MakePanel/...)` 统一入口，收敛散落的 `AddTheme*Override`。
4. **P3 装饰（克制的"气韵"）**：面板用 `blur` 毛玻璃透出 3D 场景；可加极淡宣纸纹理（非冰裂、非描金）；**红色印章**仅出现在关键节点（玩家名章、里程碑、确认弹窗的"印"按钮），数量极少。
5. **P4 微交互**：`Tween` 缓动入场、悬停抬升。
6. **P5 图标系统**：线描图标贴图，替换纯文字标签。

**风险**：① 字体文件需自备（注意授权）；② 主题需在根节点 `set`，避免个别控件局部 override 与全局主题打架（先小范围灰度：顶栏 + 建造菜单）；③ 与 3D 画面协调，面板不宜过亮过饱和。

## 五、验证
- `dotnet build` 0 错；实跑截图对比"前/后"；
- 可读性对比度达 WCAG AA（宣纸白底 + 黑字满足；青/朱仅作点缀不伤可读）；
- 与游戏 3D 画面协调、不刺眼、不遮挡操作。
