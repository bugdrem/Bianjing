# 汴京盛卷 · 玩法评审与建议

> 由 `specs/`（GAME_DESIGN / ECONOMY / DESIGN）与 `scripts/` 全量代码走查综合得出。
> 视角：游戏系统/机制设计。所有待调数值一律标 [PLACEHOLDER · 附验证路径]，未经 playtest 不落地。

## 0. 一句话结论

核心循环（规划→建造→吸引→自生长→征税→晋级）已经跑通，**涌现之城是真亮点**。但整个循环**没有终点、没有失败压力、没有目标钩子**——没有胜负、没有危机、没有任务目的。目前它更像一座会自己长出来的沙盒模型，而非"好玩"的游戏。

**最高杠杆改动**：给循环注入成败钩子（胜利结算 + 危机 + 朝廷任务链）。
**次高杠杆**：把已建却没接线的半成品（互市 / 赏赐 / 健康 / 富户消费）变成可玩。

## 1. Fun Hypothesis 与现状对照

**Fun Hypothesis（由设计原案提炼）**：以王爷之身，从河畔荒地经营出一座会自己生长的宋城，最终呈现清明上河图般的京城盛景。

| 设计意图 | 现状 | 断点 |
|---|---|---|
| 涌现（AI 居民自生长、婚育、就业、交易） | ✅ 扎实实现（`ZoneGrowthSystem` 是皇冠上的明珠） | — |
| 治理决策（划坊区、调三税、铺路网、放官营） | ✅ 决策存在 | **决策无后果 → 玩家随便调，无所谓** |
| 盛景观感（烟火气、宋韵） | ⚠️ 卷轴 + 宋风原语建筑在 | 小人方块堆叠、无姿态动画，盛景感弱 |
| 渐进之阶（8 级里程碑） | ✅ 有爬升 | **到京城(400人)即终点空白** |

## 3. 经济 Sources & Sinks（含通胀风险）

货币闭环基本健康：钱在官库 ↔ 家庭公产之间循环，多个"凭空消失"黑洞已逐个修补（柴米官营、绝户充公、营造工钱按实发、商税四舍五入）。

两处设计隐患：

- **朝廷 / 官府"凭空生成"货币**（月俸 8000 文/月、开府安家银 10 万、衙门收购凭空付钱给 NPC）：属外部活水，本身合理（类比 Caesar 的国库拨款）。但**月俸是平的白给、早期碾压一切开销** → 抹平了早期资源张力。建议改为 **递减补贴 / 有条件发放**（领地越小补贴越高），否则前期无经营压力。
- **两套粮食口径**：官粮 `gs.Food` 不计入 `DemandLedger` 可支撑天数，民粮走市场。并行易出"看着有粮却饿死"的隐性 bug。建议明确 **官粮=赈济兜底、民粮=市场**，并让官粮在饥荒时真正下发给断炊户。

## 4. 四类半成品（桩）—— 应落地或删除

| # | 半成品 | 现状 | 建议 |
|---|---|---|---|
| 1 | **互市 / 特产**（`ForeignVisitor` + `NeighborCity.Specialties`，最近一次功能） | 访客会来、会摆摊，但 `SettleVenueTrade` 进出口**没接真实供需**——城市缺盐铁时访客不会多带，粮布过剩时访客不会多买 | **接上供需**：访客按城市缺口决定带货种类与量，城市按缺口付钱 / 按过剩收钱。这是最近功能也是最大可见空洞 |
| 2 | **朝廷赏赐** | `EconomyConfig` 有 5000–50000 区间但结算未接线 | 改成**朝廷任务链**（如"今冬前供粮 1000 石，成则赏、败则削税权"），给生产以目的 |
| 3 | **Health 系统** | `Citizen.Health=100` 字段预埋但零逻辑 | 要么接瘟疫/疫疾事件，要么删字段。**设计红线：不写假装能用的系统** |
| 4 | **退休富户闲逛** | 仅 TODO 占位 | 富户消费是高端货品（酒馔/器用）的消费端出口，补上即激活 TierNeeds 的州城/京城级需求 |

## 5. 优先级建议（带验证路径）

### P0 — 给循环一个终点与压力（成败钩子）· 最高杠杆

- **胜利**：达成 京城(400人) 且 全城兴致≥阈值 且 不欠债 → 触发"清明上河图"完成长卷 + 结算评分。
- **危机系统**（制造 moment-to-moment 张力，呼应阶段3的治安/灾害）：饥荒 / 瘟疫 / 流寇随机发生，逼玩家用库存 / 财税 / 驻军应对。
- **朝廷任务链**：见上，给生产以目的。

> **失败信号（playtest 前先定义，否则等于没测）**：
> ① 玩家可无脑拉满税率而不破产；
> ② 到第 8 级后无操作仍"赢了"；
> ③ 任何灾难可被"什么都不做"化解。
> 任一出现 = 钩子失效，需重做。

### P1 — 接上已建半成品

- 互市供需对接（`ForeignVisitor` 闭环）。
- 朝廷任务链落地（赏赐 → 任务）。
- 富户退休消费出口（激活高端 TierNeeds）。

### P2 — 经济张力再平衡 · 需 playtest，数值标 [PLACEHOLDER]

- 月俸改为递减 / 条件补贴：**补贴 = max(0, 8000 − k×人口)**，k = [PLACEHOLDER · 验证：前期 3 个月内补贴覆盖 60%~80% 开销，后期趋近于 0]。
- 官粮 / 民粮口径统一或显式分流 + 饥荒时官粮真下发。
- 维护 / 修缮成本与收入比复核：当前破产仅是"停生长"软信号，建议破产累积到阈值触发 **"民变 / 流散"** 硬信号。

### P3 — 表现层与长期粘性

- 代理动画（哪怕 2–3 个基础循环姿态）补"烟火气"，优先级低于循环 stakes。
- 代理上限 300 + O(N) 日扫：人口冲千时做索引优化（`BuildableCells` 已示范增量索引思路，可复用到 `HomeResidents` 等）。
